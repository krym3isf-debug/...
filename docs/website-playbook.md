## How to use this file

When an audit or fix happens for a row, update Status (`Not audited` → `Reviewed — OK` / `Needs fix` / `Fixed [date]`) and add a one-line note. Don't expand this table with speculative rows for features not yet under consideration — add a row only when it becomes a real work item.
