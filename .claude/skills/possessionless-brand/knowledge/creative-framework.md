# Fashion Funnel Framework (TOF / MOF / BOF)

Use this to classify and brief ad creative. This is a qualitative framework for creative fit, not a performance-threshold framework — see `meta-ads-expert` skill for how to evaluate live performance.

## TOF — Top of Funnel
**Audience:** Cold / unaware.
**Goal:** Stop the scroll — pattern interrupt, curiosity, emotion, awareness.

Source recommendations:
- Hook within 1–2 seconds
- Lifestyle videos ~5–7 seconds
- High-energy UGC
- Engaging/trending Reel formats

Avoid: aggressive selling, too much text, boring flat lays, weak/silent hooks.

## MOF — Middle of Funnel
**Audience:** Warm / has seen the brand.
**Goal:** Trust, connection, desire, social proof, handle objections.

Formats: testimonials, reviews, behind-the-scenes, brand stories, fit pics, product detail shots, people naturally wearing the product.

## BOF — Bottom of Funnel
**Audience:** Hot / site visitors / cart users.
**Goal:** Purchase, urgency, friction removal, abandoned-cart recovery.

Formats: retargeting statics, stock urgency, direct-response videos, offer-driven carousels, reviews/proof, restock messaging.

Avoid: vague awareness messaging, unclear CTA, clutter, excessive discounting.

## Using this framework
- When reviewing a creative, first identify its *intended* funnel stage (from campaign/ad set context or brief), then judge it against that stage's goal — don't judge a TOF hook video by BOF direct-response standards or vice versa.
- If funnel stage is ambiguous from context, ask rather than assume.
